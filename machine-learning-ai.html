Machine Learning in Artificial Intelligence (AI)

How Machine Learning learns from data, relates to Artificial Intelligence, and supports cybersecurity analysis.

CECS 6005 · Principles of Information Security

Machine Learning (ML)

Machine Learning (ML) is a technology related to Artificial Intelligence (AI), in which systems use data to learn patterns, which can be used to perform predictions, classifications, or make decisions without a person having to manually program a specific rule for each situation.

Artificial Intelligence (AI)

Artificial Intelligence is a field focused on the development of systems capable of performing tasks that normally require capabilities associated with human intelligence, such as pattern recognition, information interpretation, content generation, problem-solving, and decision-making.

A simpler relationship to understand would be:

Artificial Intelligence → General field
Machine Learning → One of the technologies used within AI

For example, we can consider a system used to detect spam. In a traditional system, we could manually create rules where an email that contains certain suspicious words would be marked as possible spam.

With Machine Learning, we can provide different examples of emails previously classified as spam or legitimate. The model analyzes characteristics and patterns present in those data and learns to classify new emails.

How Does It Relate to Cybersecurity?

Machine Learning can be used to analyze large amounts of information and help identify suspicious behaviors.

Phishing Detection can help identify certain characteristics of potentially malicious emails.

Malware Detection can analyze certain characteristics or behaviors associated with malicious software.

Network/Anomaly Detection can help detect activities that deviate from the expected behavior of a network.

Fraud Detection can help identify unusual patterns associated with potential activities related to fraud.

Security Logs can help analyze large amounts of events and behaviors that could require the attention of a security analyst. For example, if an account normally logs in from Puerto Rico during the day and suddenly presents several access attempts from other locations in a short period, the system could consider this behavior abnormal and generate an alert so that it can be investigated.

Benefits of Machine Learning in Cybersecurity

One of the benefits of Machine Learning in cybersecurity is its capacity to analyze large amounts of data and events in less time than a person could do it manually. This can help organizations identify patterns and suspicious activities that could represent a threat.

It can also help security professionals prioritize alerts and focus their attention on the events that require greater investigation. However, Machine Learning must be used as a support tool along with other security measures.

Limitations of Machine Learning

A False Positive occurs when the system identifies something legitimate as a threat. An example would be blocking a legitimate email because the system thinks it is phishing.

A False Negative occurs when a threat really exists, but the system does not detect it. For example, a phishing email could pass through the system as if it were legitimate.

Training Data are the data used to build and train a Machine Learning model. If these data are insufficient, incorrect, or do not adequately represent the situations that the model will encounter, its performance can be affected.

Does Machine Learning Replace the Cybersecurity Professional?

Not necessarily, but it can help the security professional analyze large amounts of information, identify unusual patterns, and prioritize potential threats. However, these results must continue to be used in conjunction with other security controls and human analysis.

For example, a Machine Learning system can detect suspicious behavior and generate an alert, but a security analyst can investigate the situation to determine if it really represents a threat and take the necessary actions.
